# גלעם · מערכת ניהול רכש

מערכת מודולרית. כל לשונית היא מודול עצמאי שנרשם בליבה.

## שלב נוכחי
לשונית אחת: **תנודתיות חומרי גלם ומדדי מאקרו**, עם שש תתי-לשוניות —
נייר, אנרגיה ופלסטיק, שערי מטבע, הובלה ימית, הכימיקלים של גלעם, משברים ומחסור.

## שלוש שכבות נתונים
| שכבה | משמעות | דוגמאות |
|---|---|---|
| A — מקור שוק ישיר | API חי, מתעדכן אוטומטית | שער יציג בנק ישראל, ברנט, WTI, גז, תירס |
| B — אינדקס מנוהל | אין מקור חינמי; הערך מוזן ונשמר כסדרה | עיסת נייר, פולימרים, FBX, Drewry, מחירי כימיקלים |
| C — הערכת AI | מודל שפה, מסומן ככזה | סריקת משברים, קריאות שוק, נימוקי משא ומתן |

## שכבת ה-AI
המודל **לעולם אינו מביא נתונים**. הוא מקבל מספרים שהמערכת חישבה ומנסח מהם.

| משימה | היכן | על מה היא נשענת |
|---|---|---|
| `risk` | לשונית המשברים | כותרות חדשות אמיתיות, ממוספרות. התרעה בלי הפניה נפסלת בשרת |
| `brief` | נייר, אנרגיה, מטבע, הובלה | ערכי הסדרות והשינויים שחושבו ב-`api/_lib/market.js` |
| `pitch` | שורות הכימיקלים | מנועי העלות, ההובלה והפער שחושבו ב-`api/_lib/analysis.js` |

## הגנת הגישה
**כרגע כבויה לפי בקשה.** הקוד נשאר במקומו, והערכים שמורים ב-Vercel תחת
`AUTH_USER_OFF` ו-`AUTH_PASS_OFF`. להפעלה: להחזיר את שמות המשתנים
ל-`AUTH_USER` ו-`AUTH_PASS` ולפרוס מחדש. אין צורך בשינוי קוד.

כשההגנה פועלת, האתר סגור מאחורי שם משתמש וסיסמה. `middleware.js` רץ לפני כל בקשה — דף, קובץ
עיצוב או `api/` — ומעביר הלאה רק מי שמחזיק עוגייה חתומה ב-HMAC-SHA256.
אין כאן שום בדיקה בדפדפן, ולכן כיבוי JavaScript או פנייה ישירה ל-API לא עוזרים.

| קובץ | תפקיד |
|---|---|
| `middleware.js` | שומר הסף. חוסם, מפנה למסך הכניסה, ומחזיר 401 ל-API |
| `api/_lib/auth.js` | חתימת האסימון, בדיקת הפרטים, עוגיות. משותף ל-Edge ול-Node |
| `api/login.js` | כניסה, יציאה, ומי מחובר. חוסם IP לרבע שעה לאחר 8 ניסיונות |
| `login.html` | מסך הכניסה, עומד בפני עצמו ואינו תלוי בשאר האתר |
| `test/auth.mjs` | 40 בדיקות: חתימה, זיוף, פקיעה, cron, ומסלול הכניסה המלא |

שם המשתמש והסיסמה אינם בקוד — הם משתני סביבה ב-Vercel, כי המאגר ציבורי.
החלפת `AUTH_PASS` מנתקת מיד את כל מי שמחובר. אם `AUTH_USER` או `AUTH_PASS`
אינם מוגדרים, האתר נפתח כרגיל — שגיאת הגדרה לא נועלת אותך בחוץ.

## הוספת לשונית חדשה
1. `assets/js/tabs/<name>/index.js` שקורא ל-`registerTab({ id, he, render })`
2. שורת `await import` אחת ב-`assets/js/core/app.js`

## הוספת מקור נתונים חדש
1. פונקציית מתאם ב-`api/_lib/providers.js` שמחזירה `[{series_id, d, value, source, tier}]`
2. רישום ב-`ADAPTERS`
3. עדכון `provider` של הסדרה ב-`series.json`

## משתני סביבה
| משתנה | נדרש ל- |
|---|---|
| `DATABASE_URL` | היסטוריה, תנודתיות, מחירים — מוגדר אוטומטית ע״י Neon |
| `NVIDIA_API_KEY` + `NVIDIA_MODEL` | שכבת ה-AI. מוגדר ופעיל |
| `ANTHROPIC_API_KEY` או `GEMINI_API_KEY` | חלופה עדיפה — חיפוש ברשת מובנה. נבחר אוטומטית אם קיים |
| `AUTH_USER` + `AUTH_PASS` | הגנת הגישה לאתר. בלעדיהם האתר פתוח |
| `AUTH_SECRET` | חתימת עוגיית ההתחברות. בלעדיו נגזר מהסיסמה |
| `CRON_SECRET` | הגנה על הצילום היומי, רשות |
