# מערכת לניהול רכש גלעם

אתר סטטי (`index.html`) + פונקציית שרת אחת (`api/store.js`) ששומרת את הנתונים ב-Postgres,
כך שכל המשתמשים רואים את אותם נתונים מכל מחשב.

## הקמה ב-Vercel (פעם אחת)

1. **Add New → Project** ← ייבוא המאגר `galam-procurement` ← Framework Preset: **Other** ← Deploy.
2. בפרויקט: **Storage → Create Database → Neon (Postgres)** ← Connect לפרויקט.
   זה מוסיף אוטומטית את משתנה הסביבה `DATABASE_URL`.
3. **Settings → Environment Variables** ← להוסיף `APP_PASSWORD` = סיסמת הכניסה למערכת.
4. **Deployments → Redeploy** כדי שהמשתנים ייכנסו לתוקף.

הטבלה `galam_store` נוצרת אוטומטית בבקשה הראשונה.

## מה נשמר במסד הנתונים

| מפתח | תוכן |
|---|---|
| `data` | דוח הזמנות רכש פתוחות |
| `supdata` | קובץ ספקים |
| `spenddata` | דוח ספנד |
| `supmeta` | הערות/נתונים ידניים על ספקים |
| `crit` | פריטים קריטיים |
| `ok` | סטטוסים שמסומנים כתקינים |

ערכת הצבעים והסיסמה נשמרות רק בדפדפן. פתיחת `index.html` ישירות מהמחשב עובדת בלי שרת (נתונים בדפדפן בלבד).

מגבלה: Vercel מקבל עד ~4.5MB לבקשה, כך שקובץ Excel גדול במיוחד לא יישמר בשרת (תופיע הודעה).
